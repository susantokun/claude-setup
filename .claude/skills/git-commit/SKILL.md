# Commit Message

Format: `Prefix(scope): deskripsi`

Prefix: WIP, WIR, Feat, Fix, Refactor, Perf, Style, Docs, Test, Chore, Build, Revert, Hotfix

Aturan: scope huruf kecil, deskripsi pakai kata kerja huruf kecil, tanpa titik akhir, maksimal 72 karakter. Breaking change pakai `!` sebelum titik dua. Dilarang pesan generik seperti "update" atau "fix bug".

Contoh: `Feat(auth): tambah login via Google`
